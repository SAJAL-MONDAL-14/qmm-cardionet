# QMM-CardioNet 🫀

Multimodal AI system for heart disease prediction using ECG signals and clinical data.

## Features
- ECG 1D CNN (PTB-XL)
- Clinical MLP
- Multimodal Fusion Network
- Terminal-based prediction
- Research-ready architecture

## Dataset
- PTB-XL (PhysioNet)
- Clinical CSV features
